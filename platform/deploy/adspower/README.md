# AdsPower и агент на нашем сервере

Ставится AdsPower без окна (headless) и агент Bananabun. Оба работают на сервере nespizdili.lol под отдельным пользователем `adsagent`:
- **Права.** У `adsagent` нет sudo и нет доступа к `/opt/affiliate`, `.env` сайта и базе.
- **Память.** AdsPower ограничен 6 ГБ памяти и двумя ядрами, агент — 1 ГБ.
- **Доступ.** API AdsPower (порт 50325) отвечает только изнутри сервера.

Всё управляется ручным workflow **GitHub → Actions → «AdsPower on the server» → Run workflow**.

## Что нужно один раз

1. **GitHub Secrets** (Settings → Secrets and variables → Actions):
   - `ADSPOWER_API_KEY` — ключ API AdsPower: в приложении AdsPower → «API» → сгенерировать или скопировать ключ.
   - `BANANABUN_AGENT_KEY` — ключ агента. Подходит тот же, что сейчас лежит на Mac в `~/scripts/.bananabun_agent_key`. Новый ключ из «Настроек» отключит агент на Mac.
2. **Ссылка на `.deb`**: страница загрузки AdsPower → Linux → ссылка на файл `.deb` (https, домен adspower). Её вставляют в поле `deb_url` при установке.
3. **Номера профилей**, с которыми агенту можно работать, — в поле `allowed_serials`, через запятую (например `7,8,12`). Остальные профили агент не покажет сайту и не откроет. Пусто при первой установке — все профили.

## Переключение с Mac на сервер

1. На Mac остановить агент: `launchctl unload ~/Library/LaunchAgents/com.bananabun.agent.plist`
2. Run workflow → `install` с `deb_url` и `allowed_serials`.
3. Run workflow → `status`:
   - все три сервиса `active`;
   - Local API отвечает;
   - список «listeners outside loopback» пуст.
4. На сайте «Аккаунты» → «Синхронизировать», потом «Проверить» у одного профиля.
5. Если что-то не так — откат: Run workflow → `stop`, на Mac `launchctl load ~/Library/LaunchAgents/com.bananabun.agent.plist`.

Обновить код агента после изменений в `mac-agent/`: `install` без `deb_url`. Ключи и список профилей остаются, если поля пустые.

## Важно

- **У каждого профиля должен быть свой прокси.** Без прокси Facebook увидит IP сервера, на котором стоит сайт. Проверить до переключения.
- **Не запускать два агента с одним ключом** (Mac и сервер одновременно): они будут брать одни и те же задачи и открывать одни и те же профили.
- **Ключ AdsPower виден в списке процессов.** AdsPower принимает его только параметром запуска, а в Linux параметры процессов по умолчанию видны всем пользователям сервера, в том числе пользователю сайта. Скрыть можно настройкой `/proc` с `hidepid=2` (отдельное решение по серверу). Сам ключ даёт доступ только к AdsPower, и его API слушает только изнутри сервера.
- **Если AdsPower без окна не стартует** (`logs` покажет ошибку дисплея), на сервере добавить `ADSPOWER_XVFB=1` в `/etc/bananabun/adspower.env` и сделать `restart`.
- **Если `status` покажет порт `adsagent` вне 127.0.0.1**, добавить его диапазон в `ADSPOWER_BLOCK_PORTS=30000:40000` в том же файле и сделать `restart`.
- **Логи** (`logs`) показываются со скрытыми ключами и токенами. Токены FB, пароли, прокси и заметки профилей агент наружу не отдаёт, как и на Mac.
