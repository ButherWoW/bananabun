# Bananabun — правила для ИИ-агентов (ChatGPT/Codex, Claude)

Перед работой прочитай `docs/HANDOFF.md` (журнал, новые записи сверху) и `docs/CLAUDE_HANDOFF.md`.

## Как работаем вместе
- Участники: владелец (решения), Claude (ревью, слияние, выкатка), ChatGPT и второй разработчик dev2 со своим Claude (код). Новичку — `docs/ONBOARDING.md`.
- Каждый работает в своей ветке от `main`: `chatgpt-<задача>` / `claude-<задача>` / `dev2-<задача>`. Коммить по шагам.
- Перед началом — запись в журнале, какие файлы берёшь; чужие забронированные файлы не правь.
- Закончил шаг — допиши СВЕРХУ в `docs/HANDOFF.md` запись, начинающуюся с `## @claude …` (или `@chatgpt`, `@dev2`, `@owner`): ветка и коммит, что сделано, что проверено, что осталось. Claude следит за этим файлом и сам проверяет ветку.
- Журнал правится только в `main`.
- Не правь чужую незакоммиченную работу. Не переписывай историю (`--force`, `reset --hard`) общих веток.
- На сервер выкатывает и агента Mac перезапускает только Claude после проверки. Порядок: сервер (`platform/ship.sh`), потом агент.

## Устройство
- `platform/backend` — Node 20, Fastify, PostgreSQL; `platform/frontend` — React 18, Vite; `mac-agent/` — агент на Mac владельца (AdsPower, FB, Amazon, 2FA).
- Прод: https://nespizdili.lol. Работаем полностью без FA (клиент FA — заглушка).
- Проверки: `node --test platform/backend/test/standalone.test.js`, `npm run build --prefix platform/frontend`.

## Правила — обязательны
1. Чужие кампании не трогать. Keitaro общий: никаких пробных POST, алиасы не менять, без фильтра FR в обычном потоке.
2. В FB всё создаётся на ПАУЗЕ; включение — только с подтверждения человека. Ставка и бюджет — от лида, не по умолчанию. Код 190 — стоп.
3. Graph API — только через профиль AdsPower. Токены FB, пароли, прокси, заметки профилей, ключи и коды 2FA никуда не выводить (ни в логи, ни в чат, ни в файлы).
4. Ничего не выдумывать: отзывы, рейтинги, остатки, таймеры, скидки, «официальные ответы», события Purchase. Старая цена — только реальная. Без подделки под реальные магазины.
5. Байер видит только своё; owner/lead — всё.
6. Секреты не коммитить (`.env`, ключи, `mac-agent/fb/`).
