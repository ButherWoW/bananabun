# Target, Best Buy и Etsy — собственные адаптеры

Подготовлено 29 октября 2026 в ветке `chatgpt-marketplaces`. FA не используется.

Сервер принимает прямые ссылки на товары, создаёт сохраняемое задание `scrape_target`, `scrape_bestbuy` или `scrape_etsy`. Агент открывает страницу в выбранном владельцем профиле AdsPower, в той же очереди, что Amazon/Walmart. После результата сервер сохраняет фотографии с разрешённых CDN. Повторная обработка завершённого задания не создаёт новую партию изображений.

Поддержанные формы ссылок:

- Target: `/p/название/-/A-12345678`.
- Best Buy: старые `/site/название/1234567.p` и новые `/product/название/J3GW7QQSXX`.
- Etsy: `/listing/1234567890/название`, включая региональный префикс.

Чтение данных: Product в JSON-LD, массивы и `@graph`, точная цена Offer, валюта, название, описание, фотографии и опубликованный рейтинг. Для Target и Best Buy предусмотрено чтение отдельного элемента цены после загрузки интерфейса. Долларовая цена в этом режиме относится к американским Target/Best Buy; для Etsy валюта берётся из данных предложения. Миграция 027 сохраняет `source_currency`; интерфейс больше не подписывает все цены как Amazon/EUR.

Диапазон цен, разные предложения и неоднозначный товар вызывают явную ошибку. Автоматический выбор варианта и перенос выбранного варианта через параметры ссылки не реализованы. Если сайт не опубликовал данные, они остаются неизвестными. CAPTCHA не решается и не обходится. Изображения вне разрешённых CDN не запрашиваются; редиректы загрузок запрещены.

Проверки: 62 серверных теста с настоящими PostgreSQL и Chromium, включая синтетические страницы всех трёх магазинов, цены вариантов, отсутствие валюты, блокировки, сохранение фото, восстановление и повтор результата. Сборка и проверки интерфейса прошли. Проверки браузерного чтения входят в общий набор при `RUN_BROWSER_TESTS=1`.

**Граница готовности:** тесты используют синтетические страницы и изолированную базу. Публичная страница Target проверена для формы ссылки и загрузки интерфейса; прямой серверный запрос Etsy получил 403, Best Buy не открылся. Это не подтверждает работу через настоящий профиль AdsPower. Claude должен проверить по реальному товару каждого магазина после ревью, применения миграции 027 и согласованного обновления сервера/агента. До этой проверки не считать три магазина подтверждёнными на рабочем сайте.
