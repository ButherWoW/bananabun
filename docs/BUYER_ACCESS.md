# Изоляция байеров

Ветка `chatgpt-buyer-access`, база `0293b6a`.

По правилу AGENTS.md личные записи байера доступны только автору. Owner/lead видят записи своей команды; записи другой команды недоступны всем ролям.

Проверены списки и прямые обращения к товарам, отзывам, креативам, пресетам, локальным шаблонам, заданиям поиска, мастеру залива и локальным сводкам аналитики. Общая папка остаётся категорией команды, но больше не раскрывает чужие товары. Избранное, изменения и удаление чужих пресетов запрещены. Привязать свой товар к личной папке или пресету другого байера либо другой команды нельзя.

Создание залива проверяет автора креативов, связь с выбранным товаром, наличие готового файла и отсутствие повторяющихся ID до постановки задания. Компиляция, проверка лендинга, загрузка в Keitaro и генерация рекламного текста проверяют права на товар и локальный шаблон до побочных действий.

Миграция `021_search_owner.sql` добавляет автора результатов поиска. Старые задания без автора остаются доступны owner/lead; произвольного байера им не назначаем. То же правило действует для старых личных пресетов/шаблонов без автора: байер их не видит. Общие справочники Keitaro этим изменением не переделываются. Публичные URL опубликованных рекламных изображений остаются публичными.

Проверки из корня после установки зависимостей:

```sh
node --test platform/backend/test/standalone.test.js
BANANABUN_TEST_DATABASE_URL=postgresql://USER:PASSWORD@127.0.0.1:PORT/buyer_access_test node --test platform/backend/test/buyer-access.test.js
npm run build --prefix platform/frontend
```

Тест требует отдельную локальную базу с именем, оканчивающимся на `_test`. Создаёт и удаляет только собственную схему. Применяет исходную schema.sql и миграции в этой схеме. Работает с настоящими маршрутами Fastify и PostgreSQL; аутентификацию заменяет тестовыми пользователями, поэтому не проверяет пароли/JWT. Все внешние запросы в тесте запрещены.

Пройдено: 6 прежних тестов; 9 сценариев доступа внутри одного интеграционного набора (10 отметок Node test runner); сборка Vite. Рабочая база, FB, Amazon, Keitaro не изменялись. Перед выкаткой объединить с ветками Claude и повторить тесты. Файлы scrape.js и campaigns.js принадлежат его параллельной работе; дополнительные проверки ссылок на товар/пресеты там переданы ему в журнале.
