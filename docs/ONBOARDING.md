# Подключение разработчика к Bananabun

Ты третий участник команды разработки. Сейчас код пишут: владелец ставит задачи и решает, **Claude** проверяет, сливает и выкатывает, **ChatGPT** пишет отдельные части. Твой Claude прочитает правила проекта сам (`CLAUDE.md` в корне), ChatGPT/Codex — `AGENTS.md`.

## 1. Что это за проект

Своя платформа арбитражной команды, полностью без внешних сервисов вроде FA:
товар (скрап Amazon / Walmart) → креативы (свой рендер) → лендинг (свой шаблон на 12 гео) → кампания в Keitaro → залив в Facebook через профили AdsPower (на паузе) → аналитика.

- Прод: https://nespizdili.lol
- Код: https://github.com/ButherWoW/bananabun (приватный)
- Статус и дорожная карта: https://claude.ai/artifact/MknNeMxeP3URZ2ZRFabKUC
- Журнал работы команды: `docs/HANDOFF.md` (новые записи сверху)

| Часть | Где |
|---|---|
| Сервер API (Node 20, Fastify 5, PostgreSQL 16) | `platform/backend` |
| Панель (React 18, Vite 8) | `platform/frontend` |
| Агент на Mac владельца (AdsPower, Facebook, Amazon, Walmart, 2FA) | `mac-agent/` |
| Выкатка на прод (только Claude/владелец) | `platform/ship.sh` |

## 2. Доступы — что ты получаешь и чего нет

| Доступ | Как | Что прислать владельцу |
|---|---|---|
| Код | приглашение в репозиторий GitHub | свой GitHub-ник |
| Панель | учётка на nespizdili.lol | email |
| Сервер (SSH) | только если нужен: отдельный пользователь, вход по ключу | публичный ключ — одна строка из `~/.ssh/id_ed25519.pub` (приватный ключ никому) |

**Не выдаются и не нужны для работы:** пароль root, ключ Keitaro (трекер общий с другими командами), токены Facebook, ключ AdsPower, ключ агента, пароль базы, JWT-секрет. Если когда-то понадобится секрет — владелец передаёт лично через менеджер паролей, не файлом и не в чат с ИИ.

## 3. Поднять проект у себя (5 минут)

Нужны Node.js 20.19+ и Docker Desktop.

```sh
git clone https://github.com/ButherWoW/bananabun && cd bananabun
node platform/setup-local.mjs
cd platform && docker compose up --build -d
docker compose run --rm backend sh -c 'npm run db:migrate && npm run db:seed'
```

Открыть http://127.0.0.1:3000 и войти владельцем, которого создала последняя команда. Это твоя локальная копия с пустой базой — к проду она не подключена. Подробности и запуск без Docker: `platform/README.md`.

Проверки (из `platform/backend`, нужна отдельная локальная база с именем на `_test`):

```sh
npm test
BANANABUN_TEST_DATABASE_URL=postgresql://USER:PASSWORD@127.0.0.1:PORT/bananabun_test RUN_BROWSER_TESTS=1 npm test
```

## 4. Как работаем

1. Бери задачу у владельца или из дорожной карты. Перед началом напиши в `docs/HANDOFF.md` запись `## @claude <дата> — от dev2: беру …` и перечисли файлы, которые будешь трогать — чтобы ChatGPT и Claude их не правили одновременно.
2. Работай в своей ветке от `main`: `dev2-<задача>`. Коммить по шагам. Новые миграции — следующим свободным номером, номер тоже пиши в журнал.
3. Закончил — тесты зелёные — `git push` ветки и запись `## @claude … — от dev2: готово`: ветка, коммит, что сделано, что проверено, что не сделано.
4. Claude проверяет, сливает в `main` и выкатывает. **Сам на прод не выкатывай** и не запускай `ship.sh`, `setup-local` или `seed` против прода.
5. Журнал правится только в `main` (`git pull` → правка → коммит → `git push`), чтобы переключение веток не подменяло файл.

## 5. Правила — обязательны (полный список в `AGENTS.md`)

- Чужие кампании не трогать. Keitaro общий: никаких пробных запросов на запись.
- В Facebook всё создаётся на паузе; включение — только с подтверждения человека. Ставка и бюджет — от владельца/лида, не по умолчанию.
- Ничего не выдумывать: отзывы, рейтинги, остатки, таймеры, скидки, «официальные ответы», события Purchase. Старая цена — только реальная и в той же валюте. Без подделки под реальные магазины.
- Защиту сайтов (капчи, проверки на робота) не обходить: скрап останавливается с понятной причиной.
- Байер видит только своё.
- Секреты не коммитить; токены, пароли, ключи и коды 2FA никуда не выводить.

- Права доступа: `platform/backend/src/middleware/access.js`

- Креативы: `routes/creatives.js`, `services/creative-*.js` (очередь в базе)
- Лендинги: `services/landing-compiler.js`, шаблон — `services/landing-assets/store.html`
- Кампании FB и аналитика: `routes/campaigns.js`, `services/fb-campaigns.js`, `routes/analytics.js`
