# Проверка новой установки и зависимостей

28 октября 2026. Ветка `chatgpt-bootstrap`. Инструкция запуска: [platform/README.md](../platform/README.md).

## Изменения

- Пустая PostgreSQL получает основные таблицы перед миграциями. Одновременные миграции сериализуются, ошибочный файл откатывается вместе со своей отметкой.
- Миграция 026 добавляет поля настроек Keitaro и тип задания `similar`, отсутствовавшие в исходной схеме. Данные существующей установки не сбрасываются.
- Seed создаёт единственного первого владельца и команду. На заполненной установке отказывается работать, включая одновременный запуск; существующие пароли не меняет.
- Подготовщик настроек создаёт случайные секреты с правами 600, отказывается перезаписывать существующие файлы. Порты Docker публикуются только на 127.0.0.1. Файлы и база сохраняются в отдельных томах.
- Docker устанавливает Chromium. Загрузка фото товара, генератор и раздача файлов используют согласованный UPLOADS_DIR. Интерфейс проксирует API и изображения на сервер внутри Docker.
- Неиспользуемые jimp, bull, redis и zod удалены после проверки импортов. Fastify и плагины обновлены, bcrypt заменён на bcryptjs с проверкой старых хешей. Vite, его React-плагин и Router обновлены совместно.

## Подтверждено

- 48 серверных проверок без ошибок и пропусков: настоящая PostgreSQL, пустая установка, защита владельца, конкурентные миграции, откат, права байеров, очереди, восстановление, загрузка фото через API и получение JPEG из очереди.
- Полный набор выполнен на Node.js 20.20.2; сборка и браузерные проверки интерфейса тоже прошли на Node 20.
- Повторная установка `npm ci` по обоим lock-файлам успешна. Свежий онлайн `npm audit` для обоих пакетов: 0 известных уязвимостей. Это результат проверки зависимостей, а не полный аудит приложения.
- Новая изолированная установка Docker: сборка обоих образов, новая база и миграции, seed, вход через прокси интерфейса, ручное создание товара, фото, логотип, готовый JPEG системным Chromium, чтение пустых настроек Keitaro. Повтор seed отказал; после перезапуска сервера прежний пароль и изображение сохранились. Все опубликованные порты проверены как 127.0.0.1.

Полный Docker-прогон использовал случайные секреты, отдельные свободные порты и одноразовые тома. Первоначальная попытка запуска зависла в Docker Desktop; после очистки только тестовых контейнеров повторный запуск завершился успешно. Общий Docker и рабочие контейнеры не перезапускались.

Минимум для локальной разработки: Node 20.19; для Node 22 — 22.12. В сборке остаётся предупреждение о размере JS-файла. Новые версии не проверяют автоматически рекламные кабинеты и сторонние сервисы.

## Границы

Рабочий сервер, Mac-агент, реклама и Keitaro не изменялись этой проверкой. Слияние, выкатка миграции 026, установка зависимостей и перезапуск рабочей системы остаются за Claude по общим правилам проекта. Реальные Walmart/другие магазины, оформление заказа и собственный залив требуют своих проверок. FA не подключался.
