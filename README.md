# Bananabun

Собственная платформа товаров, креативов, лендингов и рекламы: React, Fastify/PostgreSQL, Keitaro и агент AdsPower на Mac. **FA не используется и не требуется.** Старые ключи FA не включают интеграцию.

Актуальная передача Claude: [docs/CLAUDE_HANDOFF.md](docs/CLAUDE_HANDOFF.md). План завершения: [docs/roadmap.html](docs/roadmap.html). Исходный присланный HTML сохранён в [docs/roadmap-original.html](docs/roadmap-original.html).

## Что работает в собственном режиме

В коде есть Amazon через агент, шаблонные креативы, свои лендинги, интеграция Keitaro и свой FB-агент. Наличие кода не означает, что каждый маршрут проверен с реальными сервисами. Own-адаптеры Walmart, Target, Best Buy и Etsy ещё не реализованы. Генератор изображений собирает HTML-макеты; идея, логотип и выбранный лендинг пока не влияют на результат.

## Проверка доработки без FA

После установки зависимостей в `platform/backend` и `platform/frontend`:

```sh
node --test platform/backend/test/standalone.test.js
npm run build --prefix platform/frontend
node platform/backend/test/standalone-browser.mjs
node platform/frontend/test/standalone-smoke.mjs
```

Браузерным проверкам нужен Chromium Playwright. Они не обращаются к рабочей базе и рекламным кабинетам. Границы проверки подробно описаны в передаче Claude.

## Запуск и оставшаяся работа

Backend использует PostgreSQL и секрет JWT из своего окружения; `npm run db:migrate` и `npm run dev` выполняются в `platform/backend`. Интерфейс запускается `npm run dev` в `platform/frontend`. Для совершенно новой базы сначала нужно проверить полноту миграций и создание первого владельца: чистая установка текущего состояния не подтверждена. В текущем исходном коммите сервер и dev-интерфейс слушают 0.0.0.0, поэтому запуск сам по себе не обеспечивает доступ только с одного компьютера.

Нужно закончить восстановление фоновых задач, права на списки, неработающие параметры генератора и сквозную проверку собственного залива. Тестовая реклама создаётся на PAUSED после выбора владельцем всех параметров. Эта доработка не развёртывалась на рабочем сервере.

Старый [REVIEW](docs/REVIEW.md) описывает отдельную проверочную копию и содержит исторические выводы. Его результаты нельзя автоматически переносить на текущую ветку.
