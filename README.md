# Bananabun

Собственная платформа товаров, креативов, лендингов и рекламы: React, Fastify/PostgreSQL, Keitaro и агент AdsPower на Mac. **FA не используется и не требуется.** Старые ключи FA не включают интеграцию.

Актуальная передача Claude: [docs/CLAUDE_HANDOFF.md](docs/CLAUDE_HANDOFF.md). План завершения: [docs/roadmap.html](docs/roadmap.html). Исходный присланный HTML сохранён в [docs/roadmap-original.html](docs/roadmap-original.html).

## Что работает в собственном режиме

В коде есть Amazon через агент, шаблонные креативы, свои лендинги, интеграция Keitaro и свой FB-агент. Наличие кода не означает, что каждый маршрут проверен с реальными сервисами. Own-адаптеры Walmart, Target, Best Buy и Etsy ещё не реализованы. Генератор собирает HTML-макеты с буквальной надписью и загруженным логотипом; задания и параметры сохраняются в базе. Подробности: [docs/OWN_CREATIVES.md](docs/OWN_CREATIVES.md). Это не генеративный AI.

## Проверка доработки без FA

После установки зависимостей в `platform/backend` и `platform/frontend`:

```sh
node --test platform/backend/test/standalone.test.js
npm run build --prefix platform/frontend
node platform/backend/test/standalone-browser.mjs
node platform/frontend/test/standalone-smoke.mjs
```

Браузерным проверкам нужен Chromium Playwright. Они не обращаются к рабочей базе и рекламным кабинетам. Границы проверки подробно описаны в передаче Claude.

## Запуск и оставшаяся работа

Порядок новой локальной установки: [platform/README.md](platform/README.md). Подготовщик создаёт индивидуальные секреты, миграции создают пустую базу, seed добавляет первого владельца без общего пароля. Локальные порты Docker и dev-интерфейс ограничены 127.0.0.1. Запуск миграций с нуля, откат ошибочного файла, одновременные запуски и защита существующего владельца проверены на отдельной PostgreSQL.

Права байеров и восстановление скрапа проверены на тестовой PostgreSQL. Очередь креативов, надпись и логотип проверены локально. Автогенерация после скрапа тоже восстанавливается и защищена от повторной партии. Остаются собственные адаптеры прочих магазинов и сквозная проверка собственного залива. Тестовая реклама создаётся на PAUSED после выбора владельцем всех параметров. Статус выкатки отдельных этапов — в docs/HANDOFF.md.

Старый [REVIEW](docs/REVIEW.md) описывает отдельную проверочную копию и содержит исторические выводы. Его результаты нельзя автоматически переносить на текущую ветку.
